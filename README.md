## 🎯 Lab Description

This lab course teaches students the basics of C++ programming language and its principles, with a primary focus on data structure implementation. The course motto is **"We will learn together"** - encouraging students to ask questions without hesitation. Every question is warmly welcomed and appreciated. Upon completion, students will have a clear and concise understanding of data structures and algorithms through practical implementation.

---

## 🧩 Lab Topics Covered

1. **Introduction and Dynamic Memory Allocation** – Memory management fundamentals in C++
2. **Class and Object Implementation** – Object-oriented programming concepts
3. **Template Classes** – Generic programming techniques in C++
4. **Unsorted and Sorted Lists** – Array-based list implementations
5. **Stack Implementation (Array)** – Array-based stack data structure
6. **Queue Implementation (Array)** – Array-based queue data structure
7. **Stack and Queue (Linked List)** – Linked list implementations
8. **Unsorted and Sorted Lists (Linked List)** – Linked list-based list implementations
9. **Recursion** – Recursive algorithm implementation and practice
10. **Binary Search Trees (BST)** – Tree data structure implementation
11. **Graph Data Structures** – Graph representation and algorithms
12. **Final Lab Examination** – Comprehensive practical assessment

---

## 🎓 Learning Outcomes

Upon successful completion of this lab course, students will be able to:

- **LO1:** Implement dynamic memory allocation techniques in C++ programs
- **LO2:** Design and implement classes and template classes for data structures
- **LO3:** Develop array-based and linked list-based data structures
- **LO4:** Implement stack and queue data structures using different underlying representations
- **LO5:** Apply recursive programming techniques to solve problems
- **LO6:** Construct and manipulate binary search trees
- **LO7:** Implement graph data structures and basic graph algorithms
- **LO8:** Debug and test data structure implementations effectively
